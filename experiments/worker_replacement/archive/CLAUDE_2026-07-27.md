## Experiment design rule: never disable an agent's CORE tools

CORE tools give an agent ACCESS to the environment and are ESSENTIAL for it to operate at all. We do NOT create a competence gap by removing a core tool — that doesn't degrade a worker, it switches it off entirely and forces it to output nothing (empirically: it declines rather than estimating), which is detrimental to results and reduces the study to a binary on/off switch. A competence gap must GRADE the quality of what a worker can do while it remains fully operational — e.g. tier the DATA it can access (full population vs. a sample) using ONE shared, full-capability tool everyone holds — not gate which operations its tool permits. Every worker must always be able to act.

## Competence-tier design rule: separate tiers by a genuine complexity jump, not a withheld primitive

Risk: many "advanced" statistics are algebraically DERIVABLE from simple primitives if the model can do exact algebra (which it demonstrably can — see the calculator no-go). E.g. mean/variance/std/correlation are all closed-form functions of `Σx, Σx², Σxy, n`. So a "weak" tool that hands out `sum()`+`count()` does NOT reliably create a gap for variance/std/corr — a competent model can just derive them itself, silently collapsing the manufactured gap back to zero (the same failure mode as the calculator finding). Median/percentile are the one exception (genuinely irreducible — no finite set of moment sums determines them), but relying on that exception case-by-case is fragile.

Fix: don't try to enumerate/withhold the exact sufficient statistic. Instead, separate tool tiers by a REAL, LARGE computational complexity jump, where no plausible amount of in-context reasoning bridges the gap regardless of what the weaker tool already returned. Example: weak tool = `variance()` (a single moment), strong tool = `pdf()` / distribution-shape fitting (not derivable from a variance number alone, requires genuinely more sophisticated computation). The weaker tool still always returns a real, useful, non-refused result (consistent with the core-tool rule above — nobody is ever denied output) — the gap comes from the complexity distance to what the harder task actually requires, not from hiding data or refusing operations.

This is a summary of a discussion about the current Ad Hoc Teamwork papers and directions, and it is likely not exhaustive, and it is free to change.

Ad Hoc Teamwork Mechanisms — Concise Summary by Axis
Axis 1 — New, unknown (but fixed) teammate at episode start
PLASTIC (Barrett et al., AIJ 2016/17): maintains a library of models/policies from previously-encountered teams; at deployment, Bayesian belief updates over that library identify which stored team the new teammate most resembles (PLASTIC-Policy scores similarity by comparing currently-observed state transitions against stored ones), then reuses the corresponding policy. Works when new teammates resemble past ones.
AATEAM (Chen et al., AAAI 2020): same library idea, but trains one attention network per stored type; attention over the recent state trajectory (not just single transitions) scores which type matches the current teammate in real time, improving recognition when behaviors are only distinguishable over longer horizons.
BRDiv (Rahman et al., TMLR 2022): addresses training-population quality instead of inference — generates a set of training teammates by maximizing best-response diversity (each teammate's best-response policy must differ), so an agent trained against the set is robust to a wider behavioral range at deployment.
ROTATE (Wang et al., 2025): replaces the fixed training population entirely with an open-ended minimax loop — a teammate generator trains (via PPO) new teammates that maximize the ego agent's per-state cooperative regret (gap between the teammate's return with its own best response vs. with the ego agent, evaluated from self-play, cross-play, and mixed SXP states to prevent self-sabotage), while the ego agent (history-conditioned S5 recurrent policy) trains to minimize regret against a growing population buffer of all teammates generated so far. Alternates for a fixed budget of iterations.
Axis 2 — Same teammate changes behavior mid-episode
Sum posterior / HBA (Albrecht, Crandall & Ramamoorthy, AIJ 2016): replaces the standard multiplicative Bayesian likelihood (∏ per-step action probabilities — which over-commits to old evidence and gets stuck after a switch) with an additive one (Σ per-step probabilities), so normalized beliefs approximate the empirical frequency each hypothesized type has fit the behavior — staying responsive to switches and able to represent mixed strategies.
ConvCPD (Ravula, Alkoby & Stone, IJCAI 2019): treats switch detection as image classification — builds a (types × recent-timesteps) matrix of per-step action likelihoods, and a supervised CNN classifies whether/where the "best-explaining type" trace breaks, outputting the pre/post type pair; on detection, the belief tracker resets its posterior from the changepoint, discarding stale evidence. Requires the type space to be known.
PPAS (Santos et al., EPIA 2021): wraps PLASTIC-Policy's stored team models in a Hedge-style experts algorithm — each stored model is an "expert" whose weight is multiplicatively boosted/decayed by how well it predicts the teammate's recent actions; regret guarantees from online learning theory hold against arbitrarily (even adversarially) switching teammates, unlike Bayesian tracking which assumes a fixed generative process.
ODITS (Gu et al., ICLR 2022): drops discrete types entirely — a privileged "teamwork situation" encoder (sees global state, training only) and a local-only proxy encoder both output Gaussians over a continuous latent teammate variable; an information-theoretic loss forces the proxy to approximate the privileged view from local observations alone. At deployment the drifting latent conditions the policy and a value ("integrated") network, so behavior switches appear as continuous latent drift, tracked online with no detect-and-reset event.
Axis 3 — Team size/composition changes (open teams)
GPL (Rahman et al., ICML 2021): represents each present agent as a node in a fully-connected coordination graph. A recurrent GNN (RFM) does per-timestep message passing to predict each teammate's next action; the joint Q-value is factorized into individual + pairwise utility terms over edges, with pairwise payoffs computed as low-rank products of embeddings from two shared MLPs (β, δ) — parameter sharing across all nodes/edges means agents entering/leaving just adds/removes nodes, no architecture change. Trained via TD learning; actions selected by an E-HBA-style rule over the composed Q.
GPL-JMLR / VAE-GPL (Rahman et al., JMLR 2023): extends GPL to partial observability — a variational autoencoder infers the agent-model information (previously computed from full state) from the learner's local observations alone. (Mechanism from secondary sources.)
CIAO (Wang et al., ICML 2024): reframes open AHT as a dynamic Coalitional Affinity Game (hedonic game), proving why GPL's pairwise Q-factorization ensures stable temporary coalitions; derives from the theory a representation constraint plus a graph-structure-dependent regularizer bolted onto GPL, tested with star (CIAO-S) and complete (CIAO-C) graphs.
NAHT/POAM (Wang et al., NeurIPS 2024): generalizes to controlling a variable subset of N agents among uncontrolled teammates. Independent PPO with one fully-shared policy/value network across all controlled agents; each agent's RNN encoder compresses its own observation-action history into an embedding (decoder trained to predict teammate behavior) that conditions its policy/value. New controlled agents are just new forward passes through shared weights (cold RNN state); new teammates are only sensed implicitly via drift in the local-history embedding — no explicit per-teammate representation.
Adaptive-to-learner teammates (mostly open)
LILI (Xie et al., CoRL 2020): models repeated interactions as Hidden-Parameter MDPs — teammate strategy zᵢ is fixed within an interaction but evolves as a function of the ego agent's own previous trajectory (z_{i+1} ~ f(·|zᵢ, τᵢ)). An encoder predicts the next z from the ego's trajectory, trained without labels by requiring a decoder to reconstruct the next interaction's transitions/rewards from it; the RL objective sums reward across interactions, so gradients flow through the latent dynamics and the agent learns to act now to steer the teammate's future strategy (demonstrated: herding an adaptive air-hockey opponent toward favorable shots). Limitations: change modeled only between episodes, not within; brittle with real humans.
Markovian teammate (Chakraborty & Stone, AAMAS 2013): earlier non-deep treatment — teammate is an unknown Markov policy (possibly reacting to the learner) identified online within a game-theoretic framework; historical root of taking reactive teammates seriously in AHT.

One-line takeaway per axis: Axis 1 = match the stranger to (or generate better) prior experience; Axis 2 = keep beliefs responsive when the match goes stale (additive beliefs, change detection, expert weights, or continuous latents); Axis 3 = make the architecture size-agnostic (graphs + parameter sharing); adaptive teammates = model your own effect on the teammate's future policy — still the least-solved corner.
